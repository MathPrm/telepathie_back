# User stories : Télépathie

## User story 1 - STORY CRITIQUE
"En tant que patient, je veux réserver un rendez-vous médical afin de consulter un professionnel de la santé."

## User story 2
"En tant qu'utilisateur, je veux rechercher un praticien par nom, prénom ou spécialité afin de trouver le professionnel de santé qui me correspond.

## User story 3
"En tant que praticien, je veux définir mes horaires de disponibilité afin de proposer des créneaux de rendez-vous cohérents.

## User story 5
"En tant que praticien, je veux un calendrier regroupant les créneaux de consultation réservés afin d'organiser mes journées."
